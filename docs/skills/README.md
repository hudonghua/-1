# docs/skills/

**Cursor Agent 的可复用技能 / SOP 目录**。每个 `.md` 文件描述一个独立、可执行的操作流程，Agent 在合适场景下会读取并遵循。

## 建议放进来的技能（按用户既有的体系）

| 文件名 | 适用场景 |
| --- | --- |
| `embedded-c-safe-edit.md` | 嵌入式 C 源码安全编辑流程 |
| `safe-edit-gbk.md` | GBK / GB2312 编码源码的无损编辑流程 |
| `backup-and-edit.md` | 大改动前的备份策略 |
| `verify-before-answer.md` | 回答前的事实核验流程，避免臆造 |

> 文件名只是约定，写什么内容、叫什么名字由你决定。Agent 会按 `AGENTS.md` 加载本目录下所有 `*.md`。

## 一个技能文件的推荐结构

```markdown
# <技能名>

## 何时使用
描述触发条件。例如：编辑 `*.c` 且文件编码非 UTF-8 时。

## 前置检查
- 检查 1
- 检查 2

## 步骤
1. ...
2. ...
3. ...

## 失败处理
出问题时如何回滚 / 报告。

## 反例（避免）
- 不要直接用 sed 改 GBK 文件，会乱码。
- ...
```

## 注意

- 技能文件**只放过程与规则**，不要塞凭证或个人隐私。
- 同一类操作的不同变体可以拆成多个文件，便于 Agent 按需挑选。
